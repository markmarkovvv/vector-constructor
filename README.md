# VectorCraft: Конструктор векторных композиций (MVP)

## 🚀 Быстрый запуск проекта

### 1. Бэкенд (Laravel 11 / PHP 8.5)
```bash
cd backend
# При первом запуске (если необходимо):
# composer install
# php artisan migrate --seed
php artisan serve
```
> Бэкенд запускается на **`http://127.0.0.1:8000`** и использует SQLite (без необходимости настраивать сторонние СУБД).

### 2. Фронтенд (Vue 3 + Vite + Tailwind CSS)
```bash
cd frontend
# При первом запуске:
# npm install
npm run dev
```
> Фронтенд запускается на **`http://localhost:5173`**.

## 🎨 Минимальный демонстрационный сценарий (согласно ТЗ)

1. **Открыть исходную SVG-иллюстрацию:**
   В шапке или в левой панели нажмите кнопку **«Каталог 20 иллюстраций»**. Откроется галерея 20 векторных сцен в едином стиле (*Urban Life & Workspace*).
2. **Выделить элемент:**
   Нажмите **«Открыть инспектор»** у любой иллюстрации (например, «Городская кофейня»). В интерактивном окне инспектора наведите курсор на желаемый объект (или выберите группу из списка обнаруженных объектов) — выделится контур, рассчитается ограничивающий контейнер (`bbox`) и сформируется изолированный SVG.
3. **Добавить в библиотеку компонентов:**
   Укажите название и категорию, затем нажмите **«Сохранить в библиотеку»** (или «Сохранить и сразу добавить на холст»).
4. **Собрать новую композицию:**
   Перетащите или добавьте кликом элементы минимум из 3 разных исходных иллюстраций (например: *Здание кофейни*, *Велосипедист*, *Ветвистый дуб*, *Кресло*, *Корги*).
   - Перемещайте объекты мышью (с поддержкой сетки Grid Snap).
   - Масштабируйте за угловые маркеры с сохранением пропорций.
   - Вращайте с помощью верхнего маркера поворота.
   - Управляйте слоями (выше, ниже, на передний/задний план) на панели справа.
5. **Экспортировать в SVG:**
   Нажмите синюю кнопку **«Экспорт SVG»** в верхнем правом углу. Ознакомьтесь с живым превью и исходным кодом, затем нажмите **«Скачать .SVG файл»**.

## 🏛️ Архитектура сервиса

### 1. Хранение SVG-элементов
- **Исходные иллюстрации (`Illustration`):** хранят целостный SVG документ с заголовками, группами объектов `<g id="..." data-name="..." data-category="...">` и базовым `viewBox="0 0 800 600"`.
- **Извлечённые компоненты (`Component`):** хранят нормализованный изолированный векторный фрагмент, собственный расчётный `view_box` (например, `70 140 360 340`), физические размеры `width`/`height`, метаданные и внешние зависимости (блок `<defs>` с градиентами/масками).
- **Сохранённые композиции (`Composition`):** содержат координаты `(x, y)`, габариты `(width, height)`, угол `rotation`, флаги отражения `flipX`/`flipY`, порядок слоёв `zIndex`, прозрачность `opacity` и ссылку на компонент.

### 2. Извлечение элементов (SVG Extractor & Inspector)
- **DOM-инспекция:** SVG рендерится внутри интерактивного холста инспектора. Обработчики событий мыши находят ближайшую логическую группу узла (`target.closest('g[id], g[data-name]')`).
- **Расчёт геометрии:** с помощью метода `element.getBBox()` вычисляются точные локальные координаты объекта `(minX, minY, width, height)`. К ним добавляется адаптивный отступ (padding) для предотвращения обрезки обводок (stroke).
- **Сбор зависимостей:** модуль `extractReferencedDefs` парсит фрагмент на наличие ссылок `url(#...)` и переносит соответствующие `<linearGradient>`, `<radialGradient>`, `<clipPath>` и `<filter>` из родительского документа в состав изолированного компонента.

### 3. Переиспользование и векторная сборка композиции (SVG Compiler)
- **Истинная векторность (без растра):** при сборке не используется HTML Canvas с растеризацией `toDataURL('image/png')`.
- Итоговый документ генерируется модулем `compileToSvg()` в виде чистого XML SVG документа:
  - Формируется единый блок `<defs>` всех задействованных элементов (без дублирования id).
  - Каждый объект встраивается в собственный слой `<g transform="translate(...) rotate(...) scale(...)">` с вложенным масштабируемым `<svg viewBox="..." preserveAspectRatio="xMidYMid meet">`.
  - Слои сортируются в точном соответствии со значениями `zIndex`.
  - Результат открывается и редактируется в Figma, Adobe Illustrator, Inkscape и любых браузерах без потери качества.

## 📁 Примеры готовых композиций

В папке `examples/` находятся 3 демонстрационные векторные композиции, собранные из элементов разных иллюстраций:
1. `examples/example_1_urban_boulevard.svg` — Городской бульвар (элементы из: Кофейня, Парк, Велопрогулка).
2. `examples/example_2_creative_studio.svg` — Творческая мастерская (элементы из: Офис, Студия живописи, Книжный уголок).
3. `examples/example_3_park_and_cafe.svg` — Отдых в парке (элементы из: Сад на крыше, Пикник, Площадка для питомцев, Скейт-парк).
